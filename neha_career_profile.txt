**Interview Prep for Neha – AI/ML Internship**

### 5 Technical Questions & Model Answers  

| # | Question | Model Answer (≈2‑3 sentences) |
|---|----------|--------------------------------|
| 1 | **Why is Python preferred for AI/ML over Java?** | Python has a rich ecosystem of libraries (TensorFlow, PyTorch, scikit‑learn) that simplify model building, plus concise syntax that speeds prototyping. While Java is powerful for production systems, most research and tutorials are Python‑centric. |
| 2 | **Explain the bias‑variance trade‑off.** | Bias is error from overly simplistic assumptions; variance is error from sensitivity to training data fluctuations. A good model balances both—low bias for accuracy and low variance for stability—often achieved with regularization or ensemble methods. |
| 3 | **How would you handle missing values in a dataset?** | First, assess the missingness pattern (MCAR, MAR, MNAR). Then choose an appropriate strategy: drop rows/columns if missingness is minimal, impute with mean/median for numerical data, or use model‑based imputation (e.g., K‑NN) for more complex cases. |
| 4 | **What is gradient descent and when would you use it?** | Gradient descent iteratively updates model parameters in the opposite direction of the loss gradient to minimize error. It’s used for training differentiable models such as linear regression, logistic regression, and neural networks. |
| 5 | **Describe a simple end‑to‑end ML pipeline for a classification task.** | 1) Collect raw data → 2) Clean & preprocess (handle missing values, encode categoricals) → 3) Split into train/validation/test → 4) Feature engineering (scaling, selection) → 5) Train a model with scikit‑learn → 6) Evaluate using accuracy/F1 → 7) Save model (pickle) → 8) Deploy via Flask API for inference. |
